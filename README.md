# \# 🎬 Projeto Netflix BST — Estrutura de Dados em Java

# 

# Projeto desenvolvido para a disciplina de Estrutura de Dados utilizando uma Árvore Binária de Busca (BST/ABB) para armazenar e analisar dados do dataset da Netflix.

# 

# A aplicação realiza a leitura do arquivo `titles.csv`, organiza os programas em memória utilizando o `id` como chave da árvore e permite executar diversas operações e análises sobre os dados.

# 

# \---

# 

# \# 📚 Sobre o Projeto

# 

# O objetivo principal do projeto foi aplicar conceitos de:

# 

# \- Estruturas de Dados

# \- Árvores Binárias de Busca (BST)

# \- Manipulação de arquivos CSV

# \- Ciência de Dados básica

# \- Busca, inserção e remoção em árvores

# \- Análise de dados em Java

# 

# Os dados utilizados foram retirados de um dataset público da Netflix contendo informações sobre filmes e séries, como:

# 

# \- título

# \- tipo

# \- descrição

# \- ano de lançamento

# \- classificação indicativa

# \- gêneros

# \- notas IMDB/TMDB

# \- popularidade

# \- votos

# \- países de produção

# \- entre outros

# 

# \---

# 

# \# 🌳 Estrutura Utilizada

# 

# A aplicação utiliza uma:

# 

# \## BST (Binary Search Tree)

# 

# Onde cada nó da árvore armazena um objeto `ProgramaNetFlix`.
